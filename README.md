
# 🤖 AI Coding Assistant

An AI-powered coding assistant built using Generative AI, RAG, FAISS, and Streamlit.

## Features

- 💻 Python Code Generation
- 🐞 Code Debugging
- 📄 PDF Question Answering
- 🔎 Semantic Search
- 🧠 Retrieval-Augmented Generation (RAG)

## Tech Stack

- Python
- Google Gemini
- FAISS
- Sentence Transformers
- PyPDF
- NumPy
- Streamlit

## Architecture

User
↓
Streamlit
↓
PDF Processing
↓
Text Chunking
↓
Embeddings
↓
FAISS
↓
Relevant Context
↓
Gemini
↓
AI Response
